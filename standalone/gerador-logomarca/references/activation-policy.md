# Política de ativação

## Objetivo

Delimitar quando `gerador-logomarca` deve ser considerada pelo host. A decisão real de roteamento pertence ao host; esta política orienta metadata, instruções e avaliações, sem simular o roteador.

## Deve ativar

Ative para objetivos cujo resultado principal seja identidade de marca ou sistema de logo, inclusive:

- “Crie uma logomarca para minha empresa.”
- “Preciso de um logo para uma oficina.”
- “Quero desenvolver a identidade visual da minha marca.”
- “Faça um símbolo para minha empresa.”
- “Me ajude a criar um conceito de logo.”
- “Quero redesenhar minha logomarca.”
- criar wordmark, lettermark, monograma, emblema ou símbolo de marca;
- definir direção visual, paleta ou tipografia como parte de um projeto de identidade;
- criar prompt de imagem especificamente para gerar/explorar uma logomarca;
- revisar um logo quanto a legibilidade, escalabilidade e coerência de marca.

## Não deve ativar

Não ative quando o objetivo principal não for identidade de marca:

- “Crie uma foto de uma paisagem.”
- “Faça uma ilustração de um cachorro.”
- “Edite esta fotografia.”
- “Crie um banner publicitário.”
- “Faça um desenho técnico.”
- dúvidas genéricas de Photoshop, Illustrator ou ferramentas sem contexto de branding;
- criação isolada de post, thumbnail, embalagem ou anúncio sem pedido de sistema de identidade;
- geração de ícone funcional de interface sem função de marca;
- edição cosmética de uma imagem que apenas contém um logo, quando o logo em si não deve mudar.

## Casos de fronteira

- **“Crie um ícone para meu app.”** Ative apenas se “ícone” significar marca/app icon como elemento de identidade; não ative para ícone funcional de UI.
- **“Crie uma mascote para minha empresa.”** Ative se a mascote fizer parte explícita da identidade visual; caso seja apenas uma ilustração promocional, não ative.
- **“Escolha cores para minha empresa.”** Ative se a intenção for paleta de marca/identidade; não ative para decoração, UI isolada ou impressão sem branding.
- **“Faça um cartão de visita.”** Ative somente se o trabalho incluir definição ou revisão da identidade; se a identidade já estiver fechada e o pedido for apenas layout, não é o workflow principal desta Skill.
- **“Crie embalagem para minha marca.”** Ative se o pedido envolver construir/revisar a identidade que governará a embalagem; não ative para execução isolada de packaging design com identidade pronta.
- **“Transforme este desenho em logo.”** Ative: o objetivo é converter uma ideia em marca; primeiro avalie briefing e adequação.
- **“Vetorize meu logo sem mudar nada.”** Em geral não ative: é tarefa técnica de vetorização. Ative se também houver redesign ou avaliação de identidade.
- **“Quero um logo no estilo da Nike/Apple/etc.”** Ative para branding, mas aplique a política de propriedade intelectual: extraia somente atributos abstratos e crie solução independente.
- **“Avalie se posso registrar este logo.”** Pode ativar para revisão visual, mas não para concluir disponibilidade jurídica; se o objetivo for jurídico, esclareça a limitação e não emita parecer de registrabilidade.

## Ambiguidade e prioridade

1. Priorize o objetivo final declarado pelo usuário.
2. Se branding for apenas incidental, não ative.
3. Se o pedido combinar branding e outro trabalho, use esta Skill para a parte de identidade e ferramentas/skills adequadas para o restante.
4. Se uma única pergunta curta resolver a fronteira (“ícone de marca ou ícone de interface?”), pergunte em vez de presumir.
